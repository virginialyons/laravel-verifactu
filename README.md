# Laravel Verifactu

Issue VERI*FACTU invoices from a Laravel app through the Verifactu service.

This package is built for the company's own apps. The full guide arrives with `0.1.0`.

## Requirements

- PHP 8.4+ with `ext-bcmath`
- Laravel 13

## Installation

```bash
composer require vlec/laravel-verifactu
```
